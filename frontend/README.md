# Cranvila Waffle: React frontend

React 18 + Vite + React Router.

## Run
```
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

## Structure
- src/pages: Home, About, Menu, Tracking, Contact
- src/components: Header, Footer, WaffleCard
- src/data.js: menu items, phone number, demo orders
- public/images: waffle illustrations and favicon (the tab icon)

Demo order IDs: CW1001, CW1002, CW1003. Change the phone number in src/data.js.
